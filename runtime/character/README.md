# character

Hides **what a character looks like**.

- `face`: assembles a head from FaceGen `.tri` morphs, head parts and the
  per-NPC facetint bake.
- `chargen` / `chargen_layout`: the character creator UI and the preset format
  it reads and writes.
- `fp_equipment`: the first-person weapon/torch policy, turning the player's
  inventory into a drawn viewmodel.
