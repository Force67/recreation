# editor

Hides **the in-game Creation-Kit-style map editor** (F4). `editor` is the tool
itself (asset browser, click-to-place, move/rotate/scale/delete, undo, grid
snap, selection inspector), `editor_catalog` builds the browsable asset list
from the loaded records, and `editor_io` + `editor_layout` are the layout file
it saves and loads.
